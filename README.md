# 🌟 مستقبلنا التعليمي - منصة تعليمية تفاعلية للأطفال

## 📖 نبذة عن المشروع

**مستقبلنا التعليمي** هو موقع تعليمي تفاعلي مصمم خصيصاً للأطفال من الصف الأول إلى السادس الابتدائي. يجمع الموقع بين التعليم التقليدي والمهارات المتطورة مثل البرمجة والمهارات الرقمية، بطريقة ممتعة ومناسبة للأطفال.

## ✨ المميزات الرئيسية

### 🎨 تصميم مناسب للأطفال
- ألوان مشرقة وجذابة
- شخصية تفاعلية ودودة (المساعد الذكي)
- واجهة بسيطة وسهلة الاستخدام
- رسوم متحركة ممتعة

### 📚 محتوى تعليمي متطور
- **الصف الأول**: أساسيات الحروف والأرقام مع البرمجة البسيطة
- **الصف الثاني**: تطوير مهارات القراءة والكتابة مع اللغة الإنجليزية
- **الصف الثالث**: البرمجة مع Scratch والمهارات المتقدمة
- **الصف الرابع**: تحليل البيانات والبيئة والاستدامة
- **الصف الخامس**: ريادة الأعمال والذكاء الاصطناعي
- **الصف السادس**: إدارة المشاريع والتفكير العالمي

### 🎮 أنشطة تفاعلية
- ألعاب تعليمية ممتعة
- ألغاز ذكية لتطوير التفكير
- قصص تفاعلية مشوقة
- برمجة بصرية بالكتل (Scratch-like)
- فنون رقمية وأدوات الرسم
- آلة موسيقية تفاعلية

### 🏆 نظام التتبع والتحفيز
- شارات وإنجازات قابلة للفتح
- نظام نقاط تفاعلي
- تتبع التقدم اليومي
- تحديات يومية مثيرة

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكلة المحتوى
- **CSS3**: التصميم والرسوم المتحركة
- **JavaScript**: التفاعلية والوظائف
- **Local Storage**: حفظ التقدم محلياً
- **Font Awesome**: الأيقونات
- **Google Fonts**: خط Cairo للعربية

## 🚀 كيفية التشغيل

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- لا يتطلب خادم ويب (يعمل محلياً)

### خطوات التشغيل
1. قم بتحميل جميع الملفات
2. افتح ملف `index.html` في المتصفح
3. ابدأ رحلة التعلم!

```bash
# إذا كنت تريد تشغيل خادم محلي
python -m http.server 8000
# أو
npx live-server
```

## 🎯 الصفحات والوظائف

### الصفحة الرئيسية (`index.html`)
- نظرة عامة على جميع الصفوف
- المساعد التفاعلي
- نظام الشارات والنقاط
- أنشطة متنوعة

### صفحة الصف الأول (`grade1.html`)
- مسار التعلم اليومي
- ألعاب الحروف والأرقام
- برمجة بصرية بسيطة
- تتبع النجوم والتقدم

### صفحة الصف الثالث (`grade3.html`)
- استوديو Scratch للبرمجة
- مشاريع تفاعلية متنوعة
- نظام الإنجازات المتقدم
- تحديات برمجية

## 🎨 المميزات التفاعلية

### المساعد الذكي 🤖
- شخصية ودودة ترحب بالأطفال
- رسائل تشجيعية متنوعة
- تفاعل بالنقر مع جزيئات متحركة
- تغيير الرسائل تلقائياً

### نظام البرمجة البصرية 
- كتل ملونة قابلة للسحب والإفلات
- تنفيذ الأوامر بصرياً
- حفظ واستعادة المشاريع
- شخصيات متحركة قابلة للبرمجة

### الألعاب التعليمية 🎮
- لعبة الأرقام والحساب
- لعبة الحروف والكلمات
- لعبة الأشكال الهندسية
- لعبة الألوان التفاعلية

## 🏅 نظام الإنجازات

### الشارات المتاحة
- 🌟 **شارة البداية**: أول خطوة في التعلم
- 🎯 **شارة المثابرة**: الاستمرار في التعلم
- 📚 **شارة القراءة**: إتقان مهارات القراءة
- 🏅 **شارة التميز**: الوصول لمستوى متقدم
- 🎨 **شارة الإبداع**: التفوق في الأنشطة الفنية

### نظام النقاط
- 5 نقاط لكل نشاط جديد
- 10 نقاط لإكمال درس
- 15 نقاط لبدء موضوع جديد
- 20 نقاط للألعاب والتحديات
- 25 نقاط للبرمجة والمشاريع

## 🔧 التخصيص والإعدادات

### تخصيص المحتوى
يمكن تخصيص المحتوى عبر تعديل:
- بيانات الصفوف في `script.js`
- الألوان والتصميم في `styles.css`
- النصوص والرسائل في ملفات HTML

### إضافة صفوف جديدة
1. إنشاء ملف HTML جديد (مثل `grade2.html`)
2. إضافة الصف إلى `gradePages` في `script.js`
3. تخصيص المحتوى والأنشطة
