# منصة ترخيصي - ولاية منوبة

منصة إلكترونية متطورة لتقديم طلبات ترخيص التاكسي الجماعي في ولاية منوبة بطريقة سهلة وآمنة وفقاً للأمر عدد 581 لسنة 2023.

## المميزات

- ✅ تسجيل المستخدمين وإدارة الحسابات
- ✅ تقديم طلبات الترخيص إلكترونياً
- ✅ رفع الوثائق المطلوبة (PDF, JPG, PNG)
- ✅ تتبع حالة الطلبات في الوقت الفعلي
- ✅ واجهة مستخدم عربية متجاوبة
- ✅ تشفير كلمات المرور
- ✅ إنشاء ملفات ZIP للوثائق
- ✅ نظام إشعارات متطور
- ✅ دعم الأجهزة المحمولة

## المتطلبات

### متطلبات النظام
- Node.js (الإصدار 16 أو أحدث)
- MongoDB (الإصدار 4.4 أو أحدث)
- متصفح ويب حديث

### التقنيات المستخدمة

#### الواجهة الخلفية (Backend)
- **Node.js** - بيئة تشغيل JavaScript
- **Express.js** - إطار العمل للخادم
- **MongoDB** - قاعدة البيانات
- **Mongoose** - مكتبة التعامل مع MongoDB
- **Multer** - معالجة رفع الملفات
- **bcrypt** - تشفير كلمات المرور
- **JSZip** - إنشاء ملفات مضغوطة
- **CORS** - إدارة الطلبات العابرة للنطاقات

#### الواجهة الأمامية (Frontend)
- **HTML5** - هيكل الصفحات
- **CSS3** - التصميم والتنسيق
- **JavaScript ES6+** - منطق التطبيق
- **Axios** - التواصل مع API
- **Font Awesome** - الأيقونات
- **Google Fonts** - خط Tajawal العربي

## التثبيت والإعداد

### 1. تحميل المشروع
```bash
git clone <repository-url>
cd taxi-license-platform
```

### 2. تثبيت المتطلبات
```bash
npm install
```

### 3. إعداد قاعدة البيانات

#### تثبيت MongoDB (Ubuntu/Debian)
```bash
# إضافة مفتاح MongoDB GPG
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -

# إضافة مستودع MongoDB
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# تحديث وتثبيت MongoDB
sudo apt-get update
sudo apt-get install -y mongodb-org

# تشغيل MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod
```

#### تثبيت MongoDB (Windows)
1. تحميل MongoDB Community Server من الموقع الرسمي
2. تثبيت البرنامج واتباع المعالج
3. تشغيل خدمة MongoDB

#### تثبيت MongoDB (macOS)
```bash
# باستخدام Homebrew
brew tap mongodb/brew
brew install mongodb-community
brew services start mongodb/brew/mongodb-community
```

### 4. إنشاء المجلدات المطلوبة
```bash
mkdir uploads archives
```

### 5. تشغيل التطبيق

#### التطوير
```bash
npm run dev
```

#### الإنتاج
```bash
npm start
```

## استخدام المنصة

### للمستخدمين

#### 1. إنشاء حساب جديد
- فتح الموقع على `http://localhost:3000`
- النقر على "تسجيل جديد"
- ملء البيانات المطلوبة:
  - رقم بطاقة التعريف الوطنية
  - البريد الإلكتروني
  - رقم الهاتف
  - كلمة المرور

#### 2. تسجيل الدخول
- النقر على "تسجيل الدخول"
- إدخال رقم بطاقة التعريف وكلمة المرور

#### 3. تقديم طلب ترخيص
- النقر على "تقديم طلب"
- ملء البيانات الشخصية
- رفع الوثائق المطلوبة:
  - نسخة من بطاقة التعريف الوطنية
  - نسخة من رخصة السياقة
  - شهادة العمل
  - شهادة الإسعافات الأولية
  - التصريح السنوي بالدخل

#### 4. تتبع الطلب
- النقر على "تتبع الطلب"
- إدخال رقم التتبع المرسل بعد تقديم الطلب
- عرض حالة الطلب والملاحظات

### للإدارة

#### عرض جميع الطلبات
```bash
curl -X GET http://localhost:3000/api/admin/applications
```

#### تحديث حالة طلب
```bash
curl -X PUT http://localhost:3000/api/admin/update-status \
  -H "Content-Type: application/json" \
  -d '{
    "trackId": "TRK123456789",
    "status": "مقبول",
    "notes": "تم قبول الطلب ويمكن استلام الترخيص"
  }'
```

## API المتاح

### المستخدمين

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/register` | تسجيل مستخدم جديد |
| POST | `/api/login` | تسجيل الدخول |
| POST | `/api/apply` | تقديم طلب ترخيص |
| GET | `/api/track/:trackId` | تتبع الطلب |

### الإدارة

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | `/api/admin/applications` | عرض جميع الطلبات |
| PUT | `/api/admin/update-status` | تحديث حالة طلب |

## استكشاف الأخطاء

### مشاكل شائعة وحلولها

#### 1. خطأ في الاتصال بقاعدة البيانات
```bash
# التحقق من تشغيل MongoDB
sudo systemctl status mongod

# إعادة تشغيل MongoDB
sudo systemctl restart mongod
```

#### 2. خطأ في رفع الملفات
- التحقق من وجود مجلد `uploads`
- التحقق من صلاحيات الكتابة
- التحقق من حجم الملف (أقل من 5 ميجابايت)

#### 3. مشاكل في البورت
```bash
# تغيير البورت في متغيرات البيئة
export PORT=3001
npm start
```
