# موقع إسعافك - خدمات نقل المرضى والإسعاف

موقع إلكتروني متكامل لشركة خدمات النقل الطبي والإسعاف باستخدام HTML، CSS، وJavaScript مع دعم كامل للغة العربية.

## 🌟 الميزات الرئيسية

### ✅ التصميم والواجهة
- **تصميم متجاوب** يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، حاسوب)
- **دعم كامل للغة العربية** مع نظام RTL
- **تصميم حديث وجذاب** باستخدام Bootstrap 5
- **أيقونات احترافية** من Font Awesome
- **خط عربي أنيق** (Cairo Font)

### 📱 الصفحات والوظائف
1. **الصفحة الرئيسية** (`index.html`)
   - قسم رئيسي جذاب مع دعوة للعمل
   - إحصائيات الشركة
   - عرض سريع للخدمات
   - قسم "لماذا نحن" مع المميزات

2. **صفحة الخدمات** (`services.html`)
   - عرض تفصيلي لجميع الخدمات
   - حاسبة تكلفة تفاعلية
   - خدمات إضافية ومساندة
   - معلومات الأسعار والباقات

3. **صفحة الحجز** (`booking.html`)
   - نموذج حجز شامل ومفصل
   - التحقق من صحة البيانات
   - قيود زمنية ذكية
   - معلومات جانبية مفيدة

4. **صفحة من نحن** (`about.html`)
   - قصة الشركة ورؤيتها
   - فريق القيادة
   - التراخيص والاعتمادات
   - أسطول الشركة

5. **صفحة التواصل** (`contact.html`)
   - معلومات اتصال شاملة
   - نموذج تواصل تفاعلي
   - خريطة الموقع
   - الأسئلة الشائعة

### 🔧 الوظائف التفاعلية
- **نماذج ذكية** مع التحقق من صحة البيانات
- **حاسبة أسعار** تلقائية
- **أنيميشن ناعم** للعناصر
- **زر العودة للأعلى**
- **تبديل اللغة** (العربية/الإنجليزية)
- **رسائل تأكيد** وتنبيهات المستخدم

## 🚀 طريقة التشغيل

### التشغيل المحلي
1. **تحميل المشروع**
   ```bash
   git clone [repository-url]
   cd ambulance-website
   ```

2. **فتح في المتصفح**
   - افتح ملف `index.html` مباشرة في المتصفح
   - أو استخدم خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 8000
   
   # باستخدام Node.js
   npx http-server
   
   # باستخدام PHP
   php -S localhost:8000
   ```

3. **الوصول للموقع**
   - افتح المتصفح وانتقل إلى `http://localhost:8000`

### نشر الموقع
يمكن نشر الموقع على أي خادم ويب يدعم HTML:
- **GitHub Pages** - مجاني
- **Netlify** - مجاني مع ميزات متقدمة
- **Vercel** - مجاني للمشاريع الشخصية
- **أي استضافة ويب** تقليدية

## 📞 الدعم والمساعدة

### المشاكل الشائعة

**1. المشكلة: النصوص لا تظهر بالعربية بشكل صحيح**
```html
<!-- تأكد من وجود lang="ar" و dir="rtl" -->
<html lang="ar" dir="rtl">
```

**2. المشكلة: النماذج لا تعمل**
```javascript
// تأكد من تحميل JavaScript بعد DOM
document.addEventListener('DOMContentLoaded', function() {
    // الكود هنا
});
```

**3. المشكلة: التصميم لا يظهر بشكل صحيح على الجوال**
```html
<!-- تأكد من وجود viewport meta tag -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
