# دليل صفحات الوجهة للبنك البريدي التونسي 🇹🇳

## الصفحات المتاحة

### 1. صفحة الوجهة الأساسية (landing.html)
**المسار**: `/landing.html`

**المميزات**:
- تصميم كلاسيكي وأنيق
- العلم التونسي المتحرك
- نسر قرطاج مع تأثيرات بصرية
- أقسام متعددة: المميزات، الخدمات، الإحصائيات
- تصميم متجاوب للهواتف والأجهزة اللوحية

### 2. صفحة الوجهة الحديثة (landing-modern.html)
**المسار**: `/landing-modern.html`

**المميزات**:
- تصميم حديث ومتطور
- تأثيرات بصرية متقدمة
- ألوان متدرجة وتأثيرات الشفافية
- حركات تفاعلية متقدمة
- تصميم أكثر عصرية

## كيفية الاستخدام

### 1. الوصول للصفحات
```
https://your-domain.com/landing.html
https://your-domain.com/landing-modern.html
```

### 2. ربط الصفحات بالتطبيق الرئيسي
يمكنك إضافة روابط في التطبيق الرئيسي:

```html
<!-- في React App -->
<a href="/landing.html" className="btn">صفحة الوجهة الأساسية</a>
<a href="/landing-modern.html" className="btn">صفحة الوجهة الحديثة</a>
```

### 3. تخصيص الصفحات

#### تغيير الألوان
```css
:root {
    --primary-red: #E70013;    /* الأحمر التونسي */
    --primary-green: #00A651;  /* الأخضر التونسي */
    --primary-white: #FFFFFF;  /* الأبيض */
    --gold: #FFD700;          /* الذهبي */
}
```

#### تغيير النصوص
```html
<!-- تغيير العنوان الرئيسي -->
<h1>منصة البنك البريدي التونسي</h1>

<!-- تغيير الوصف -->
<p>خدمات مصرفية متطورة مع العلم التونسي ونسر قرطاج</p>
```

## النشر على Vercel

### 1. رفع الملفات
```bash
# بناء المشروع
cd client
npm run build

# رفع مجلد build إلى Vercel
```

### 2. إعدادات Vercel
```json
{
  "version": 2,
  "builds": [
    {
      "src": "client/package.json",
      "use": "@vercel/static-build",
      "config": {
        "distDir": "build"
      }
    }
  ],
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/client/build/index.html"
    }
  ]
}
```

## استكشاف الأخطاء

### 1. إذا لم تظهر الصفحة
- تحقق من المسار الصحيح

### 2. إذا لم تعمل الحركات

- تأكد من تحميل Font Awesome
- تحقق من JavaScript console

### 3. إذا لم تظهر الألوان
- تحقق من متغيرات CSS
- تأكد من دعم المتصفح للألوان
- تحقق من تحميل الخطوط
